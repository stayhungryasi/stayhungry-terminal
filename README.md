# Stayhungry.ASI Terminal

A market observatory disguised as a code editor. Live at **https://stayhungryasi.github.io/stayhungry-terminal/**

- Languages: `/en/` (default) · `/ko/` · `/es/` · `/ja/`
- `_source/page.html` is the single source page. Rebuild all language pages with:
  `python3 _source/build.py _source/page.html . https://stayhungryasi.github.io/stayhungry-terminal`
- `data/` receives JSON feeds from the bots.
