4. 市場が見落としている隠れた恩恵

  1. 社内マスクショップのチェーン [推定] マスク製作まで一つの建物で行う構造は、他のファブにはない特異点だ。マスク検査（レーザーテック・KLA・ZEISS）とマルチビームマスク描画装置（IMS、インテルが過半出資）が必要になる。つまりインテルは、プロセスライセンスに加えてIMSを通じても装置収益を得る。韓国ではブランクマスク（S&Sテック）とペリクル（FST）がつながる可能性があるが、両社とも接触の報道はなく、純粋な仮説だ。

  2. 新組織の歩留まり学習コスト [推定] ファブ経験のないチームは、同じウエハー数に対して計測・検査装置をより多く買い、より長く使う。KLAやノバのようにサービス売上の比率が大きい企業が有利だ。

  3. 中国排除＋日本は高価＝韓国が代替供給先 [確定＋推定] [確定] テスラ・スペースXは中国企業と取引しない。業界では、中国を除くとサプライヤーは数社しかなく、日本は高いという評価が出ている。[推定] この構造は韓国の素材・部品・装置企業の参入には有利だが、マージンには不利だ（5-2参照）。

  4. テキサスの水・環境インフラ [推定] テスラの施設担当者が廃水再利用設備について直接問い合わせた（G&Gインテック）。スクラバーはユニセムがNDAを結んだ。同じカテゴリーだという理由だけで、接触の報道がない企業までテラファブの恩恵企業にまとめるべきではない。
